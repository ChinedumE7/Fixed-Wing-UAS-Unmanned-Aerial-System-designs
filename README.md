In this project, I designed and assembled a Fixed-Wing Unmanned Aerial Vehicle (UAV) in SolidWorks.
I created the wings, tail, and horizontal stabilizers from NACA 0012 airfoil cross-sections.
I intended to 3-d print this as a personal model, so the dimensions are scaled down as compared to real life. The fuselage is 12.5 inches long, and the wingspan is 34 inches wide.
